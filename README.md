# os_on_rust

Краткое описание:

Минималистичная операционная система, написанная на Rust в рамках изучения низкоуровневого программирования, работы с VGA-буфером, серийным портом, обработкой исключений и тестированием в "no_std" среде.

## Статус
    Учебный проект (закончен)

## Возможности на данный момент
    - Вывод текста на экран через VGA-буфер (с поддержкой цветов и переносом строк)
    - Вывод отладочной информации через последовательный порт (для QEMU)
    - Глобальный Writer с потокобезопасностью (lazy_static + Mutex)
    - Макросы print! и println! для удобного вывода
    - Интеграционные тесты (включая тесты на панику)
    - Поддержка QEMU с устройством isa-debug-exit для кодов завершения
    - Обработка прерываний и исключений CPU через IDT:
    - Аппаратные исключения: breakpoint, double fault с отдельным стеком (TSS/IST)
    - Внешние прерывания (PIC): таймер и клавиатура с маскированием
    - Асинхронное выполнение задач (собственный Executor с TaskWaker и Waker для пробуждения)
    - Обработка ввода с клавиатуры (PS/2) через прерывания:
        - Чтение скан-кодов и преобразование в символы (с поддержкой раскладки US)
        - Асинхронный поток ScancodeStream для ожидания нажатий клавиш

## Сборка и запуск
Для сборки и запуска проекта вам понадобятся:
    - Rust (требуется использовать nightly)
    - QEMU (эмулятор для запуска ядра)
    - bootimage (инструмент для создания загрузочного образа)

## Установка зависимостей
1. Rust - [setup Rust](https://rust-lang.org/tools/install/)

    Убедитесь, что Rust установлен:
    ```bash
    rustc --version
    cargo --version

2. Установите Rust Nightly если ещё не установлен.

    ```bash
    rustup install nightly
    rustup toolchain list

2. Скачайте репозиторий и установите Rust Nightly активным только для этого репозитория:

    ```bash
    git clone https://github.com/Bartiam/os_on_rust.git
    cd os_on_rust
    rustup override set nightly

3. QEMU - [setup QEMU](https://www.qemu.org/download/)

    Убедитесь, что qemu установлен:
    ```bash
    qemu-system-x86_64 --version

4. Установите компонент llvm-tools-preview:

    ```bash
    rustup component add llvm-tools-preview

5. Установите bootimage:

    ```bash
    cargo install bootimage

## Сборка и запуск

    ```bash
    cargo run
    cargo test
